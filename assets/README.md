# VELOCITY Assets Directory

- `models/` — Custom external 3D models (GLTF/GLB/OBJ). Procedural 3D weapons, knives, hands, avatars, and targets live in `src/models/`.
- `textures/` — Custom external textures and decals. Procedural PBR skin/glove/firearm materials live in `src/models/shared/skinMaterials.js`.
- `sounds/` — Custom external audio samples. Synthesized Web Audio SFX live in `src/audio/`.
